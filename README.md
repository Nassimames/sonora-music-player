# 🎵 SONORA — Feel Every Frequency

**Your universe, your rhythm.** Discover new sounds, explore different musical moods, and enjoy a music experience designed around you.

SONORA is a modern, stylish, and interactive music player built to deliver an immersive listening experience through a clean interface, smooth interactions, and a personalized music space.

## ✨ Features

* 🎧 **Music Player** — Play and pause tracks with intuitive playback controls.
* ⏭️ **Track Navigation** — Switch between previous and next tracks.
* 📊 **Playback Progress** — View track progress and navigate through the timeline.
* 🔊 **Volume Control** — Adjust the listening volume.
* ❤️ **Favorites** — Save your favorite tracks for quick access.
* 🎶 **My Playlist** — Build your own personal music collection.
* 🔍 **Explore Music** — Discover available tracks and explore the music library.
* 🕘 **Recently Played** — Easily revisit tracks you've listened to.
* 🎨 **Modern UI/UX** — Enjoy a visually engaging interface with a focus on usability and aesthetics.

> Some features may depend on the current implementation of the project.

## 🛠️ Technologies

SONORA is built with web technologies:

* **HTML5** — Application structure

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser to run the application.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Nassimames/sonora-music-player.git
   ```

2. Navigate to the project directory:

   ```bash
   cd sonora-music-player
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.

## 🎨 Design Concept

SONORA is designed around the idea that music is personal. Its interface aims to combine a contemporary visual identity with intuitive navigation, allowing users to explore music, manage their playlists, and enjoy their favorite tracks in one place.

**Design goals:**

* Clean and modern interface
* Intuitive navigation
* Interactive listening experience
* Personalized music discovery
* Responsive user experience
